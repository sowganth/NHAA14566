# NHAA 14566 — Module 3: Support, Authority Dashboard & Case Management

AI-enabled Real-Time Stress and Trauma Assessment system for victims/complainants interacting with the **National Helpline Against Atrocities (NHAA 14566)** and connected digital channels.

## Overview

Module 3 receives structured Stress & Vulnerability Index (SVI) risk assessments generated by **Module 2** (which builds on **Module 1** interaction analysis) and provides:

- Transparent rule-based support recommendation engine
- Human-review decision support workflow (`HUMAN REVIEW REQUIRED` & `URGENT SAFETY REVIEW REQUIRED`)
- Case management & status control history
- Officer & authority dashboard with non-PII metrics and Recharts visualization
- Service referral tracking (Counselling, Legal Aid / DLSA, Medical, Police Protection, Witness Protection, Social Support)
- Immutable system audit trail log
- Privacy enforcement and Role-Based Access Control (RBAC) across 6 roles

> **IMPORTANT DISCLAIMER**: This system is a decision-support and case-management prototype. It does NOT diagnose mental health conditions, determine guilt or innocence, make autonomous legal/arrest/police orders, or replace trained counsellors, lawyers, medical professionals, or helpline officers.

---

## Complete Pipeline Architecture

```text
       INPUT (Text / Voice Narrative)
                 ↓
      MODULE 1: Interaction Analysis
                 ↓
      MODULE 2: SVI Assessment & Risk Categorization
                 ↓
      MODULE 3: Support Recommendation Engine
                 ↓
      Human Officer Review & Authority Dashboard
                 ↓
      Case Management / Referral / Audit Logging
```

## Quick Start

### 1. Run Backend (FastAPI + SQLite + Pytest)

```bash
cd backend
python -m pip install -r requirements.txt
python main.py
```

- API Base URL: `http://localhost:8000`
- Swagger Interactive Docs: `http://localhost:8000/api/docs`
- OpenAPI JSON: `http://localhost:8000/api/openapi.json`
- Health Check: `http://localhost:8000/api/health`

### 2. Run Backend Tests

```bash
python -m pytest backend/tests -v
```

### 3. Run Frontend (React + Vite + Tailwind CSS)

```bash
cd frontend
npm install
npm run dev
```

- Frontend App URL: `http://localhost:3000`

## Role-Based Access Control (RBAC)

Use the **Active Role** dropdown switcher in the top right header to simulate any of the 6 roles:

| Role | Access & Permissions |
| --- | --- |
| `ADMIN` | Full system administration, configuration, and audit logging |
| `SUPERVISOR` | Authority Dashboard, case assignment, status updates, review approval, audit logs |
| `CASE_OFFICER` | Assigned cases, status changes, case notes, referral creation |
| `COUNSELLOR` | Authorized counselling-related cases, risk assessment view, counselling notes |
| `LEGAL_SUPPORT` | Authorized legal aid cases, DLSA referral updates, legal notes |
| `READ_ONLY` | Restricted non-sensitive dashboard and case index view |

## Main API Endpoints

- `POST /api/v1/assessment/run` — Executes full Module 1 → Module 2 → Module 3 pipeline
- `POST /api/v1/module3/recommend-support` — Generates rule-based support recommendations
- `GET /api/v1/module3/dashboard` — Returns aggregate non-PII dashboard stats
- `GET /api/v1/module3/cases` — Searchable/filterable case directory
- `GET /api/v1/module3/case/{case_id}` — Full case detail with recommendations, notes, referrals & audit history
- `PATCH /api/v1/module3/case/{case_id}/status` — Controlled status update with reason logging
- `POST /api/v1/module3/case/{case_id}/assign` — Assign case to officer
- `POST /api/v1/module3/case/{case_id}/notes` — Add case note with visibility scope
- `POST /api/v1/module3/case/{case_id}/referrals` — Create official service referral
- `GET /api/v1/module3/referrals` — All active and completed service referrals
- `GET /api/v1/module3/audit-logs` — System-wide audit log
- `GET /api/health` — Health check endpoint
